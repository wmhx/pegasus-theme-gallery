## 重新生成

```bash
python scripts/generate.py            # 增量更新（默认外链，不落盘图片）
python scripts/generate.py --force    # 全量重抓
python scripts/generate.py --download # 可选：把截图下载压缩到 assets/ 本地保存
python scripts/preview.py             # 生成 docs/index.html 网页版画廊
```

> 默认只保存图片的外链地址（仓库里没有图片文件），仓库很小；
> 但上游仓库改名/删文件时外链会失效，想要长期存档就加 `--download`。

主题列表同步自 `data/repos.txt`（上游：mmatyas/pegasus-theme-gallery-db）。
